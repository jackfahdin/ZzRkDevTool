# 全局设备状态栏设计

用户已确认底部统一设备选择方案，保留刷新与扫描时间，移除设备页列表和下载镜像页重复选择器。

## 展示与职责

底部依次为设备标签、端口下拉框、连接状态/模式/USB 版本、操作提示、刷新按钮和最近扫描时间。完整设备元数据放在悬浮提示。新增独立 QWidget 组件，装入框架 QStatusBar 的永久区域，普通操作消息不隐藏设备入口。继续使用框架控件样式、字体及主题。

工作区 ViewModel 的 selectedPortPath 是唯一当前设备来源。组件发出选择请求，控制器验证忙碌状态与设备存在后更新选择；业务页面观察结果，不保存自己的选择。

## 选择和失效规则

- 无设备时等待连接；首次仅一台自动选择，多台要求用户选择。
- 刷新保留当前端口，列表按端口稳定排序。用户选中设备移除后清空目标并显示断开，不自动切换到其他设备；再次连接需明确选择。
- 扫描失败或结果不完整时标记警告，禁止基于不完整结果自动选择；热插拔失败保留手动刷新入口及错误说明。
- 所有 USB 任务运行中禁止选择及刷新；控制器也验证，不能仅靠控件禁用。
- 端口或设备会话身份（USB 地址、VID/PID、模式和协议版本）变化时，清空详情/GPT/设备布局和预检结果，保留本地文件映射草稿。模式变化发生在同一端口也必须失效。
- 未支持设备允许查看连接元数据，但读写按钮继续受现有 RK3588 协议条件限制。
- 原有后台任务在开始时捕获目标，不因状态刷新改变请求。热插拔刷新仍使用现有 libusb 事件与去抖，不增加轮询。

## 页面与消息

设备页只保留当前设备详情与读取操作，下载镜像页只保留镜像来源和分区布局配置。底部操作提示与持久设备状态分离；配置保存失败等现有消息统一进入提示区域。支持实时中英文、字体和高亮设置；窄窗口优先保留设备选择与刷新，长文本省略并保留完整提示。

## 验证

通过可控设备后端和真实 GUI，验证多设备选择、操作目标、普通刷新、断开不转移、同端口模式/身份变化清缓存、忙碌时禁止切换、失败扫描、热插拔错误、消息不遮挡选择器及翻译。保留既有烧录/分区测试并迁移到全局入口。执行 Linux Release 全量构建、CTest、设置字体后的界面截图和独立审查。
