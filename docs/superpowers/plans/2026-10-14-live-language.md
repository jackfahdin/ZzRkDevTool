# GUI 即时语言切换

**目标：** 设置中切换简体中文、英文或跟随系统，现有窗口立即刷新文案。

**已确认设计：** 原地更新文字，不重建页面、重新扫描设备、解析镜像或启动任务。翻译绑定保存源文案及参数，在 Qt `LanguageChange` 时刷新；绑定随控件销毁。翻译器由应用持有，页面通过窗口壳层请求切换。页面数据、选择、进度和忙碌状态保持不变。已有历史输出保留原语言，新输出使用当前语言。

**文件职责：** `GuiTranslations` 提供带源信息的文案和刷新绑定；`WorkspaceUi` 统一绑定标签、按钮和进度；页面绑定选项及表头；窗口壳层切换翻译器并更新标签与标题；测试覆盖真实设置入口及状态保持。
